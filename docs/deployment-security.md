# Deployment security headers

The Foundation produces a static site. Client projects include a small,
portable baseline in `public/_headers` for hosts that support that convention
(including Cloudflare Workers Static Assets / Pages and Netlify). More specific
policy — especially CSP and HSTS — remains a per-client deployment decision so
each site can allow only the external origins it actually uses.

## Where to configure

| Platform                          | Mechanism                                                      |
| --------------------------------- | -------------------------------------------------------------- |
| Cloudflare Workers Static Assets  | `public/_headers` (included in this Foundation)                |
| Cloudflare Pages                  | `public/_headers` (included in this Foundation)                |
| Netlify                           | `public/_headers` or `netlify.toml`                             |
| Nginx / Apache                    | Server configuration                                            |

Note: on Workers Static Assets, `_headers` rules apply only to responses
served from the static assets; responses generated by Worker code (the
Foundation has none) need their headers set in the Worker script itself.

## Recommended baseline

Safe baseline already included in this Foundation's `public/_headers`:

```
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: camera=(), microphone=(), geolocation=()
X-Frame-Options: DENY
```

Enable HSTS only once the domain serves HTTPS permanently:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains
```

## Content-Security-Policy

Deliberately **not** hard-coded in the Foundation: client projects routinely
need external form embeds, analytics, or other approved origins, and a CSP
must list them explicitly.

Starting point for a client with no external resources:

```
Content-Security-Policy: default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'
```

Per client, extend it deliberately, e.g. for an embedded external form:

```
frame-src https://forms.example.com
```

Notes:

- `style-src 'unsafe-inline'` is currently required because Astro and some
  components emit small inline styles. Tighten per project if possible.
- If the site embeds an iframe (FormEmbed), add its origin to `frame-src`.
- If analytics is approved for a client, add its origins to `script-src` and
  `connect-src`.
- Test the CSP in report-only mode first:
  `Content-Security-Policy-Report-Only: …`
